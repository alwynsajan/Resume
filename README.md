# Alwyn Sajan Portfolio Resume


## Run locally

- Open `about.html` directly in your browser, or
- Open `index.html` (redirects to `about.html`).

## Deploy on GitHub Pages

- Push this repository to GitHub.
- In repository settings, enable Pages from the `main` branch root.
- Your site will load from `index.html`.

## Page views (visitor badge)

The footer shows a **visitor badge** from [visitor-badge.laobi.icu](https://visitor-badge.laobi.icu) (free). The count is stored **on their service**, not in this GitHub repo—static Pages cannot save counts by itself.

- **Stable counter:** `about.html` sets `data-visit-counter-id` on `<body>`. Use one unique string (e.g. `yourname.github.io-resume`) so every page load adds to the **same** total.
- **Where to see the number:** only on the **badge image** in the footer. There is usually **no full analytics dashboard** with these free badge APIs.
- **If the badge does not show:** ad blockers or privacy extensions often block third-party counters—try another browser or disable the blocker for your site.
- **Want charts / referrers / a dashboard?** Use something like [GoatCounter](https://www.goatcounter.com) (free tier): sign up, paste their script in `about.html`, and use their site for stats.
