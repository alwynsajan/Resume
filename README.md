# Portfolio — Alwyn Sajan

Static portfolio and resume. The site entry point is **`index.html`**.

## GitHub Pages

Enable **Pages** in the repository settings and publish from the **root** of the default branch. The live URL follows `https://<username>.github.io/<repository>/`.

## Visitor badge

The footer uses a third-party visitor badge ([visitor-badge.laobi.icu](https://visitor-badge.laobi.icu)). Counts are stored by that service, not in this repository.

The `data-visit-counter-id` attribute on `<body>` in `index.html` should stay a single stable value so all visits aggregate to one counter. Ad blockers may hide the badge. For full analytics, consider a dedicated service such as [GoatCounter](https://www.goatcounter.com).
